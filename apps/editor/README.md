# AcmePDF Viewer (Bun + React + Zustand)

PDF viewer web app for uploading, previewing, and annotating PDF files.

## Features

- Upload and preview PDF files, images, and documents
- View tools: Highlight text, Add Signature, Add Image overlays
- Export annotated PDF with overlays

## Tech Stack

- Bun
- React + TypeScript + Vite
- Zustand (state management)
- pdf-lib (PDF manipulation)
- react-pdf (PDF preview)

## Run Locally

```bash
bun install
bun run dev
```

## Build

```bash
bun run build
bun run preview
```
